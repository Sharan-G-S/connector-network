Connector Network · what we added

Making our conversions production-grade — in simple terms

Our tool converts between API formats both ways: SDK ⇄ MCP, GitHub → SDK / MCP, CLI and docs. Big tools (Stainless, Fern) had three things our output was missing. We added all three — inside the conversion itself (no servers, no GitHub push/pull). all verified green

01

Quality layer

The generated SDK behaves well in the real world
What we added

The SDKs we generate now retry failed calls and time out cleanly.

Why

Before, if the API was briefly busy (error 429/503) the SDK gave up at once — fine for a demo, not for real use.

How

Each call now retries up to 2× with a growing wait (and respects the server's “try again later”), and stops after 30s. The code stays identical — only its behaviour is smarter.

Like: redialing a busy phone number a couple of times instead of hanging up on the first beep.
02

Versioning (Infra)

Every conversion is labelled with where it came from
What we added

Each conversion drops a small cn.manifest.json into the output.

Why

We couldn’t tell which spec a generated SDK came from, or whether two outputs were the same. Big tools version their SDKs; we didn’t.

How

The label records the source, a content-hash, a version, and the operation count — no dates or file paths, so the same input always gives the same version (and a changed input gives a new one).

Like: a nutrition label on every product — exactly what’s inside, identical every time you make it.
03

Correctness QA

Every conversion is auto-checked, not eyeballed
What we added

One command — npm run qa — that tests every conversion.

Why

Before, checking a conversion meant reading the generated code by hand: slow and easy to miss things.

How

It runs all 4 inputs and checks 48 test cases — valid output, all operations present, same result every run (Passk), and a lossless round-trip (SDK→MCP→SDK loses nothing). Green = good, red = stop.

Like: a spell-checker that flags every mistake instantly, instead of proofreading by eye.

How they fit together

Any input → one IR → output, then the 3 guarantees make it production-grade.
